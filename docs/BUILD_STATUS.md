# Easy build status

Easy has a native Flutter workspace with local records and optional Calendar, model and device connections. The Linux review package exercises the core routes. The Android review packages use the development signing key.

| Work area | Current evidence |
|---|---|
| Workspace and focus | Blank and sample startup choices, optional presets, thumb navigation, tasks, notes and cross-focus capture. A confirmed event can offer an opt-in focus switch. |
| Capture | One-field entry, staged calendar times, voice with hold, lock and cancel gestures, local transcription and reviewed proposals. In-workout capture updates exact sets and returns to the same session. |
| Calendars | Device-local schedules, recurring events, iCalendar transfer, optional Apple sources and reviewed event copies. Explicitly free events stay visible without occupying planning time. Reads and active views respect reported access changes. |
| Recovery and sharing | Native history, selected restores, encrypted backups with original media, and encrypted change files for explicitly paired devices. |
| Planning and review | Verified gaps, dependencies, hard deadlines, buffers and travel feed day and week plans. Today can flag one due task that fits a verified gap. Review confirms selected blocks before saving and can show known unbooked time. |
| Workouts and nutrition | Recurring workout plans, freestyle logs, per-set actuals, previous weights, optional health measurements, recipes and manually editable meal drafts and photo suggestions. |
| AI | Offline capture, optional compatible loopback schemas, and reviewed HTTPS requests within a separate GBP allowance. Adaptive foreground estimates use the available allowance, and reviewed ranges include the timing evidence sent. Local timing can use recent confirmed comparable work. |
| Automations | Enabled rules can prepare local follow-up drafts. Applying a draft rechecks its source and saves the new record with its review state. |
| Platform verification | Linux release and offline workflow checks, Android APK and lint checks, hosted Android 36 and iPhone 17 first launches, macOS SDK build, and mocked EventKit. Physical device and live paid billing gates remain open. |
